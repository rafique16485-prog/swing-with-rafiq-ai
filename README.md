# Learn Options — Basic to Advanced with AI

हिंदी options-learning web app for beginners.

## क्या शामिल है
- 20 learning modules: basics → advanced decision science
- ELI5-style explanations
- CE/PE, strike, expiry, premium, payoff, Greeks, IV
- Probability, statistics, expectancy and R:R
- Market structure, price action, VWAP, volume and option-chain concepts
- Risk Guardian position-size practice calculator
- AI Teacher/Coach (offline rule-based V1; no browser API key)
- Mini quizzes and local progress tracking
- Psychology, discipline, journal/backtest concepts
- Mobile-first white / blue / green / yellow theme
- PWA manifest + offline service worker assets

## Safety
यह educational app है, live trading signal या profit guarantee नहीं। Real trading से पहले paper practice, transaction costs, slippage, lot-size rules और personal risk limits verify करें।

## Status
V1 learning core is complete in `index.html`. PWA/offline foundation is included. Live AI/API integration and production browser verification remain separate deployment steps; secrets must never be placed in client-side HTML.
